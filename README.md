### 🧰 核心项目

- **[zhclean](https://github.com/qlheric/zhclean)** — 中文脏数据净化器：人名/地址/电话/公司名/金额/日期/身份证/邮箱八类字段，一键规范化 + 去重 + 清洗报告。**宁可漏改，绝不改坏**——每类规则带校验闸门（身份证按 GB 11643 重算校验码才敢修），benchmark 真实数与失败案例全部公开。
